From sequence space to experimental learning

Predict the effect.
Learn from the experiment.

Most protein variants differ at only a few residues. Their functions can differ dramatically.

ProTEUS represents each variant as a state and mutations as actions. It combines sequence, evolutionary and structural context to predict the functional consequences of those actions. Mutation-biased attention brings the altered residues into focus, while a fast, physics-constrained predictor provides structural context for higher-order candidates.

Experimental measurements then update target-specific predictions and inform the next set of variants. The result is a loop between virtual exploration and measured function.

Represent the variant

Variants are states.
Mutations are actions.

A mutation moves a protein to a new state in a joint latent space. ProTEUS predicts the resulting function using the variant’s sequence, evolutionary and structural context.
